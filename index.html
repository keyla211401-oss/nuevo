Acerca de Code Power

Un proyecto creado para aprender programación mientras nos divertimos.

👩‍💻

¿Por qué hicimos Code Power?

Code Power nació como un proyecto escolar para poner en práctica nuestros conocimientos de HTML, CSS y JavaScript.

Queríamos que los ejercicios de programación no fueran solamente códigos, sino que también pudieran convertirse en una experiencia divertida e interactiva.

🎯

Nuestro objetivo

Practicar la lógica de programación, aprender a resolver problemas y crear una página web funcional.

💻

Tecnologías

HTML para la estructura, CSS para el diseño y JavaScript para crear la interacción de los juegos.

🧩

Lo que aprendimos

Variables, funciones, eventos, condiciones, ciclos, arreglos, objetos y manipulación del DOM.

Centro de ayuda

🎮 ¿Cómo jugar?

En la pantalla de inicio encontrarás cinco juegos. Presiona el botón "Jugar" del reto que quieras realizar.

🧩 ¿Qué hago si algo no funciona?

Puedes cerrar el juego y abrirlo nuevamente. También puedes utilizar el botón "Reiniciar" que aparece dentro de los juegos.

🏆 ¿Cómo ganar?

Cada juego tiene reglas diferentes. Lee las instrucciones que aparecen antes de comenzar y utiliza las pistas cuando estén disponibles.

⌨️ Atajos

Puedes utilizar ESC para cerrar un juego o ventana.
